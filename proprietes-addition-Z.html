Propriétés de l'addition

Les propriétés de l'addition vues avec les nombres naturels restent bien évidemment vraies avec les nombres entiers.

1. L'addition des nombres entiers est commutative.
Dans une somme, changer l'ordre des termes ne modifie pas le résultat.

-5 + 3 = -2 et 3 + (-5) = -2 donc -5 + 3 = 3 + (-5)

2. L'addition des nombres entiers est associative.
Dans une somme, déplacer, supprimer ou introduire des parenthèses ne modifie pas le résultat.

(-9 + 3) + 5 = -6 + 5 = -1 et -9 + (3 + 5) = -9 + 8 = -1 donc (-9 + 3) + 5 = -9 + (3 + 5)

3. L'addition des nombres entiers admet 0 comme élément neutre.
Dans une somme, le terme 0 ne modifie pas le résultat.

-8 + 0 = -8 et 0 + (-8) = -8 donc -8 + 0 = -8 = 0 + (-8)

4. Une nouvelle propriété
Pour calculer 3 + (-3), on se place sur la position 3 et on recule de 3 pas.

La somme de deux nombres opposés est égale au neutre 0.
